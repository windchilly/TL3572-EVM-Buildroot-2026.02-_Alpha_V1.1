# M7.0 增量：UP2 / ETH2 POWERLINK 主站

2026-10-10 用户确认：**UP2 作为 MN 主站，控制外部设备**。不扩展到 2oo3。
继续累计固件路线；以下阶段是开发检查点，不另开一套外设隔离交付固件。

## 功能分区

- UP2 / CPU5：POWERLINK API、对象字典、MN 节点管理、PDO/SDO、周期调度、
  ETH2 EDRV、GMAC1/MDIO/PHY、DMA 和本核相关中断。
- UP1 / CPU4：保持现有功能分配，不映射或竞争 GMAC1；实时协作以后通过既有核间通道。
- openEuler：ETH1 管理、ETH3 维护/开发对端、日志与配置管理，共享电源/根时钟保持。
  启动阶段一次性 PHY 硬复位允许；运行期不得代 UP2 收发帧、配置 PHY 或周期调度。
- 实时链路：`UP2 业务 → openPOWERLINK MN → EDRV → GMAC1/DMA → ETH2`。
  RPMsg 不承载代理物理收发；协议栈的 user/kernel 是逻辑层，均在 UP2 地址空间。

## 检查点与验收

| 检查点 | 工作 | 必须取得的证据 | 当前状态 |
|---|---|---|---|
| P0 | 完整源码固定、AArch64 核心构建 | 源码包/锁定哈希、原生状态机/对象字典测试、依赖/指令审计、独立复编一致 | 软件通过，见记录 |
| P1 | ETH2 从测试切片变为通用 EDRV | RX/TX/组播/缓冲区生命周期、及时收发、DMA 静默停止；100M 半双工 MAC/PHY 验证 | 未完成 |
| P2 | UniProton target 与高精度定时 | 内存与临界区、定时器独占、周期发帧、最坏延迟和漂移；未满足启动条件时拒绝启动 | 未完成 |
| P3 | 累计 UP2 固件接入 MN | 对象字典/内存 CDC、PDO/SDO、节点发现/配置/运行、日志、受控启停；保持既有功能 | 未完成 |
| P4 | 隔离 CN 与集成回归 | 互操作、周期抖动/最坏响应、负载、断线/重连、重复启停、原接口组合回归 | 未完成 |

目前不承诺最短周期、轴数或伺服性能；应先明确对端、节点数、PDO 长度和目标周期，
再用实测上限决定参数。ETH3 的 USB/Linux 测试对端不能作为工业实时验收依据。

## 实施约束

1. 保留已实测的两份累计 ELF 和原 M6/DT，不用软件编译成功替代上板验收。
2. 默认 passive；硬件准备未通过、ETH2 未独占、共享根关闭或定时器未就绪时不得启动 MN。
3. ETH1 管理链路保持可用；ETH2 当前仍是测试窗口移交，持久分配尚未完成。
4. CAN/RS-232/RS-485 接线改变后的“先不要发送”继续有效，不能为 POWERLINK 回归而隐式开启。
5. 按 POWERLINK DS301 第3章重新验证半双工和网络拓扑；当前 100M 全双工 L2 PASS 不等同。
6. 当前固定版本为 V2.7.2，不是新维护版本承诺。旧上游编译告警需在生产候选前逐项处理；
   文件许可证分别核对，不把完整归档内的 GPL/厂商限定平台文件自动纳入 UP2 构建。

P0 的 REAL32/REAL64 范围检查暂拒绝；若业务需要浮点对象范围语义，须补齐并验证后再启用，
不以全局关闭整数范围检查或偷偷放开 FPU 编译来通过构建。
